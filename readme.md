# ShareBridge

> Android utility helping you share files between apps

Some apps only support _opening_ files in external apps rather than _sharing_. This may prevent you from sending files to your desired app.

Opening files in ShareBridge allows you to share them freely. ShareBridge also normalizes image file extensions to ensure compatibility.

[⬇️ Download](https://github.com/kidonng/ShareBridge/releases/latest/download/app-release.apk)

## Usage

> [!NOTE]
> This app has no launcher icon. It only appears in "Open with" app choosers.

1. When viewing a file, choose **Open with** (or similar actions)
2. Choose **ShareBridge** in the app chooser
3. Choose target app in the share sheet
